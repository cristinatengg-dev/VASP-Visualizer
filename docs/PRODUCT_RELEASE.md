## 当前查看方式

```sh
npm run build
npm run preview:platform:start
```

打开 http://127.0.0.1:4317/ 。服务直接提供 `dist`，没有 Vite 开发客户端；停止和状态命令为 `preview:platform:stop`、`preview:platform:status`。它与旧开发服务共用 4317 端口，切换前先停止当前服务。再次修改前端后需要重新构建；修改后端后需要重启预览。

首次预览只复制原本机未过期的手机号会话，帮助继续查看界面，不复制挑战码、演练会话或研究/账务数据；这些会话不等于生产短信验证。所有新预览记录进入 `.preview/platform`。`.dev` 原项目、对话、文献和虚拟余额完整保留。生产入口拒绝 `.dev` 和 `.preview` 数据目录，不自动迁移本机身份到线上。

## 正式运行配置

1. 将 `scripts/platform/platform.env.example` 复制到 `.config/platform.env`，填写正式 HTTPS 来源、已审核腾讯云短信参数和模型网关参数。密钥文件应仅限服务账号读取，不入 Git。
2. 安装前后端依赖并构建，运行 `npm run start:platform`。独立入口为 `server/platform.cjs`，不读取旧 `server/.env`，不启动旧支付/计算后台。缺少 HTTPS 来源或短信配置会拒绝启动。
3. 默认存储 `.data/platform`，包含 auth 和 knowledge 子目录。使用持久磁盘并做备份；目前为单进程原子文件存储，勿多副本同时写入同一目录。既有每空间 30 项目、3000 资料、50 MB 状态等容量限制保留，扩容或数据库迁移需另行验证。
4. 在 HTTPS 反向代理后运行，保留客户端 Host，配置的 `ELIANGMAT_ORIGINS` 须与外部完整来源一致。API 代理关闭流式缓冲并允许至少 60 秒请求；生产 cookie 强制 Secure/HttpOnly/SameSite。直接本机 HTTP 不适合正式登录。
5. 容器配置为 `Dockerfile.platform` 和 `docker-compose.platform.yml`，读取同一独立配置，持久化 `.data/platform`，仅将 4320 绑定到主机回环地址，交给 HTTPS 入口转发。镜像上下文排除密钥、开发/预览/客户数据。2026-09-07 已在生产构建并启动版本化镜像，入口由 `scripts/platform/ingress.compose.yml` 与 `scripts/platform/nginx.conf` 切换，SSE 缓冲关闭；应用信任一层内部代理以正确区分客户端限流。

首次切换使用 `scripts/platform/deploy-server.sh`，先备份原服务器配置、TLS、账号、上传文件、MongoDB 与运行文件，再切换 HTTPS。旧 `deploy_to_tencent.sh` 对应旧后台，未用于本次发布。首次切换脚本会拒绝对已上线的平台重复执行；后续更新须保留现有入口配置、版本化镜像及 `.data/platform`，先备份当前平台数据，不能套用恢复旧首页的首次切换回退。

旧账号记录和研究文件仍保留在旧服务与备份中，尚未迁入新版，不能将“保留备份”视为“新页面可见”。新版使用独立持久目录，同手机号通过正式短信验证后使用新版账号；旧站会话不作为新站登录凭证。本次没有向生产导入本机 QA 数据，没有对外发送短信或产生充值。
