> 最新研发流程、任务执行、实验判定与下一轮验收，请优先阅读 [2026-09-06 研发流程修复说明](RESEARCH_FIXES_2026-09-06.md)。本文件保留初版平台接入说明。

- 页面内验收说明：http://127.0.0.1:4317/platform-guide

双击仓库根目录 `启动EliangMat开发环境.command`，或在仓库目录执行：

```bash
npm run dev:platform:start
npm run dev:platform:status
npm run dev:platform:stop
```

后台运行时关闭浏览器或终端不影响服务。重启电脑后需要重新启动；休眠时不能访问。地址只供本机使用。前端热更新，后端改动须重启；有效登录会话和账号数据会在重启后保留。

前台开发：先停止后台服务，再运行 `npm run dev:platform`。原 `dev:knowledge:*` 命令继续兼容。安装环境为 Node.js 22.16+ / 24，先执行 `npm ci`、`npm --prefix server ci`。不需要 MongoDB、Docker、短信或生产密钥。

## 建议的验收顺序

1. **首页与登录**：点三个不同章节，在画面上滚动，再点「进入工作区」。未登录时进入手机号登录页。获取页面标注的本机测试验证码并填入，成功后进入平台；完整步骤见 [登录验收指南](PHONE_LOGIN_DEV_GUIDE.md)。原演练数据从登录页「开发测试」进入客户 A。
2. **研发进度**：选择客户 A 的「高强铝合金研发 · 演练」。在协作页检查已完成、暂停、待确认等标识。打开 SEM 任务，继续、暂停，再打开应看到保存后的状态。
3. **改目标**：「目标与约束」调整样品预算或勾选 DFT。保存后路线返回待确认；已完成任务保留，旧下一轮草案失效。研究计划页确认新版本后才能继续演练。
4. **结果**：在结果页查看目标和测量的比较。复核选择「暂不纳入」时不能生成下一轮；填写原因并确认可用后可以生成草案。草案样品数量不能超过预算，需要再次勾选确认。
5. **手工记录**：候选材料 → 登记候选；实验与样品 → 登记样品 → 录入数值、测试条件和原始摘录。新记录重新进入质量复核，旧计划失效，历史记录保留。
6. **证据**：选择「镍基高温合金 · 验收测试」，确认原先 12 条资料仍在。研究项目使用同一个项目 ID；建立研究计划后可从协作页「同步已复核证据」。未许可或未复核证据不能同步；撤回检索许可后，研究报告也不再包含该引用。
7. **隐私**：新项目默认私密。参与优化须明确勾选授权；资料仍需逐份满足训练权、质量复核和非虚构条件。切回私密后停止后续训练导出。
8. **模型**：在模型页选择模型，刷新后保存。外部服务需单独确认，项目不会因此自动改成参与公司模型优化。
9. **充值**：测试充值 ¥100 → 创建 TEST 订单 → 模拟支付成功。再开始计费演练，预留 ¥1；材料模型的本例结算 ¥0.16，释放余款。重复结算不会重复扣款。另一次演练取消后释放全部预留。
10. **预算**：降低单任务/月度预算并重试，应显示明确错误；预算不足不得创建调用。修改后可恢复原预算。
11. **隔离与角色**：左下角账号菜单 → 开发测试 → 客户 B，应看不到 A 的项目和余额；演练账号在成员页切换财务视角后不能打开研发结果/资料，研究员不能充值或改用途授权。可在成员页切回所有者。手机号账号也相互隔离，角色不能自行切换。
12. **刷新、重启与重新登录**：刷新页面或停止/重新启动开发服务，有效会话仍在；退出后用同一手机号登录，资料、项目、记忆、订单和余额应保持。
13. **自动记忆**：在对话中直接补充一条测试约定 → 新对话中提问 → 自动显示此前内容；项目协作也能检索同账号内容，带有来源归属。设置中可停止引用。完整步骤见 [记忆验收指南](MEMORY_DEV_GUIDE.md)。

已准备客户 A 的独立铝合金演练项目，并完成了一轮浏览器流程验证；存在 TEST 充值和计费记录，均为虚拟资金。原有镍基合金资料项目保留。客户 B 保持空项目状态，方便用户验证隔离。

详细资料采集测试参见 [数据中心指南](KNOWLEDGE_DEV_GUIDE.md)。如果希望从初始任务状态体验，可切换到尚未建立研究路线的资料项目，在研发页创建新的独立演练项目。

## 实现与验证记录

- 前端：`src/pages/platform/`；首页：`public/platform/hero.html`。
- 统一项目状态/计费/权限：`server/src/platform/`；复用数据中心的按客户隔离存储。
- 独立 API：`server/knowledge-dev.cjs`，监听 127.0.0.1:4318；Vite 固定 4317 代理。
- 状态：`.dev/knowledge-data/<客户散列>/state.json`；原件同目录 `originals/`；日志 `.dev/knowledge.log`。
- 数据源配置来自 `.dev/knowledge.env`，可选短信配置来自 `.dev/phone-auth.env`；不读取 `server/.env`。身份与会话保存于 `.dev/platform-auth/`。
- 51 项平台、知识、记忆及新身份自动测试通过；`npm run test:platform` 会一并运行。浏览器已验证首页章节/滚动/跳转、统一导航、项目选择、SEM 状态、复核、下一轮确认、模型确认、TEST 充值/预留/结算、角色切换、A/B 隔离和 390px 窄屏导航。记忆验证包含新对话自动回忆、同账号跨项目检索、来源停用、重启保留和手机布局；登录验证包含验证码错误、成功返回原页、退出拦截和同号重新登录恢复对话/记忆。
- 自动测试：`npm run test:platform`。构建：`npm run build`。

数据存储目前为单进程、原子写入的有界开发存储。正式多人部署需迁移数据库与旧账号、完成组织邀请和成员管理、接入可靠任务调度、生产支付回调和服务适配器；开发角色切换接口不得上线。
