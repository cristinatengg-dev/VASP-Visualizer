# EliangMat AI 手机号登录验收

当前为本机开发版，未部署生产。首页公开浏览，进入研发功能时登录；登录后返回原目标页面。左侧底部账号菜单提供账号设置、退出登录及折叠的开发测试入口。

## 直接体验

1. 运行 `npm run dev:platform:start`，打开 http://127.0.0.1:4317/ 。点击右上角「登录」，或直接打开 http://127.0.0.1:4317/login 。
2. 输入手机号，点击「获取验证码」。当前默认 **本机测试验证码模式，不发送短信**；页面显示验证码，点击「填入」后「登录并继续」。中国大陆号码输入 11 位，其他地区带国家/地区代码。可使用虚构测试号码 `+12025550142` 创建独立测试账号。
3. 首次验证自动创建账号和研发空间。新项目默认私密，初始余额为零；原客户 A/B 演练资料不会混入新账号。
4. 在「对话」补充一条带特定代号的测试约定；左下角账号菜单 → 退出登录；用同一手机号重新登录，在新对话询问该代号，应找到此前记录。账号记忆仍为本地保存与检索，未接入大模型。
5. 退出后直接访问 `/workspace/results`，应进入带返回地址的登录页；成功后回到结果页。未创建项目时显示新建研究入口。
6. 换另一个手机号登录，应看不到上一账号的项目、历史对话、资料和余额。

验证码有效期 5 分钟，同一手机号重发间隔 60 秒；错误达到 5 次后须重新获取，成功使用后立即失效。错误显示在表单内，重新输入即可。会话有效期 7 天，刷新及重启开发服务后仍有效；退出会在服务端撤销会话。

## 原有客户 A/B 演练

登录页展开「开发测试」，或账号菜单 → 开发测试。选择「进入客户 A 演练」可继续原来的项目、资料与 TEST 余额；客户 B 用于隔离验证。只有演练账号在成员页显示所有者/研究员/财务视角切换。手机号账号的角色由服务端成员关系决定，不能通过测试切换接口修改。

测试角色切换不会发送邀请。多人组织加入、管理员分配角色与正式邀请仍待实现。

## 可选：开发环境启用真实短信

已复用此前手机号登录的腾讯云短信适配器。默认测试模式不读取生产 `server/.env`，也不连接生产账号数据库。真实短信使用独立配置：

1. 参考 `scripts/knowledge/phone-auth.env.example`，在 `.dev/phone-auth.env` 填写专供开发测试的腾讯云短信配置，并将 `ELIANGMAT_SMS_MODE` 改为 `tencent`。若已有该文件，保留已有配置再编辑；不要覆盖生产密钥文件。
2. 仅本机账号可读：`chmod 600 .dev/phone-auth.env`。
3. `npm run dev:platform:stop` 后执行 `npm run dev:platform:start`。
4. 页面不再展示本机验证码；使用自己能接收短信的号码验收。真实短信发送会产生供应商费用。配置缺失会拒绝启动，发送失败会显示错误，不会自动降级成测试验证码。

本轮浏览器验收使用本机验证码；腾讯适配器通过模拟发送器测试，**本轮没有发送或验证真实短信到达**。即使启用真实短信，数据仍写入本机开发空间；不会自动迁移/合并生产旧账号。

## 存储与测试

- 身份和会话：`.dev/platform-auth/`，手机号索引使用密钥散列，仅保存脱敏号码；验证码和会话令牌不以明文持久保存。
- Cookie 为 HttpOnly、SameSite=Strict；本机 HTTP 开发环境不设置 Secure。生产部署需 HTTPS、生产 Cookie 设置、持久数据库及配套验证码风控，不能上线开发角色入口。
- 资料、项目与记忆：`.dev/knowledge-data/<空间散列>/`。账号使用稳定的服务端用户/空间 ID，换会话不会丢失记录；切换账号卸载原工作区状态，其他标签页同步身份变化。
- `npm run test:platform-auth`：14 项登录测试（含原手机号适配器测试）。
- `npm run test:platform`：51 项平台、资料、记忆及新身份测试。
- 登录专项覆盖验证码过期/限次/单次使用、发送失败、冷却持久化、会话撤销、重新登录恢复同一空间、不同号码隔离、成员关系复核、Cookie 与 API 身份边界。

当前身份存储适用于单进程本机验收；正式部署需完成数据库与组织账号迁移。用户明确验收通过后再安排部署。
