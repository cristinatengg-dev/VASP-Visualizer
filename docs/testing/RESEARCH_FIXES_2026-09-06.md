## 已交付的改动

| 审查项 | 本轮修改与边界 |
| --- | --- |
| A01 目标不一致 | 删除 350 MPa 等隐式默认值；从原文提取明确数值，缺失条件留空；服务端阻止缺失、冲突目标确认。温度、标准及版本、屈服定义、环境、重复数、样品上限、周期持久保存。目标版本与路线版本分开，修改任务配置不使实验数据无故失效。 |
| A02 错误达标提示 | 由服务端统一核对复核状态、目标版本、温度、标准、指标定义、环境、试样、原始文件和成分版本。排除、缺条件或工况不符时不显示达标。独立试样统计与单条数值分开。 |
| A03 成分缺校验 | 校验元素、重复项、负数、余量、区间和总量；115% 拒绝。范围候选可保存，但确定具体配比前不能制样。旧错误记录保留并标记，不能执行。候选与样品修订有版本，已录入测量保留原快照。 |
| A04 对话能力 | 规划意图给出可编辑需求草稿入口；事实请求组合目标、路线、任务、最近结果和可比统计，并区分当前与历史轮次。继续服从记忆关闭、项目排除、来源撤销和角色权限。仍是本地结构化查询与规则，没有接通真实大模型推理。 |
| A05 任务协同 | 可定义输入、输出、方法版本、资源、负责人、期限、成本、验收条件与依赖；依赖环、旧版本、前置未验收均拦截。新增人工执行/原始文件回传/验收，以及真正执行的本机 CSV 曲线分析。支持失败、重试、取消与运行归档，上游运行和输出版本保存在下游输入。DFT、CALPHAD、MD、CFD 引擎和设备自动控制仍未接通；责任人登记不发送通知，成员邀请仍是草稿。 |
| A06 下一轮文字计划 | 草案包含候选版本、独立重复、用户指定的参考/工艺变量与取值、条件、假设、成本和停止条件。确认后实际创建新轮次、样品及任务，旧轮次归档。重复确认不会重复创建。算法是验证设计规则，不能称为模型优化或自动发现配方。 |
| A07 实验模型 | 独立试样、实际温度/标准/环境/屈服定义/应变速率/尺寸、原始文件、附加指标、逐条复核、候选/批次/工况分组、均值与样本标准差。重复导入同一试样不增加 n。数据导入不再等同于仪器执行完成。当前达标模板仍以屈服强度和延伸率为主；附加指标可保存和导出，大文件/LIMS/设备原生文件解析仍待接入。 |
| A08 文献筛选 | 默认检索式来自当前项目；新增类型、年份与可选关键词筛选，保留来源类型和版本关系。审稿记录单独标识，检索计数不等于有效证据数。材料相关性需人工核对；尚不是材料体系实体检索或完整证据覆盖评估。 |
| A09 设置范围 | 账号默认隐私/模型与当前项目覆盖项分开，常驻显示作用对象；默认项仅影响之后新建的项目。外部推理和训练候选授权分别确认。新账号显示首次研究入口。 |
| A10 交互纠错 | 保存结果后直接进入该条记录复核；候选/样品提供修订；下拉显示成分和工艺并要求明确选择；任务显示缺失前提；保留中性色，以文本和图标表达状态；导航重置页面滚动位置。 |

## 本轮 Computer Use 实测

账号：此前虚构本机测试号 `+12025550143`，仍使用原有登录会话与测试余额 99.95 元。本轮没有真实短信、真实扣款或训练。新项目为 **FIX-906 材料闭环回归 · 全部虚构**，全程私密；没有改动客户真实实验数据。

1. 从目标原文提取出 300 MPa、8%、200°C、6 个样品、4 周；补齐 TEST v1（虚构）、空气、Rp0.2、2 个独立试样后保存。页面及任务名称一致。
2. 输入 Al90/Cu20/Mg5 wt% 被拒绝，改为 Al94/Cu4/Mg2 保存成功。候选 `C-2ca6acb1` 的工艺修订到 v2，样品 `FIX-906-S1` 关联该版本及批次 `FIX-B1`。
3. 上传虚构原始 CSV，录入 25°C / 315 MPa / 9%。保存后直接进入复核；排除后结果页显示温度不符和不参与判定，不显示达标。设备任务没有因录入结果而完成。
4. 定义无设备依赖的本机曲线分析，实际运行 8 个点，得到峰值 370 MPa、积分 29.89 MJ/m³。输出先等待人工验收，验收后归档；图形和数值可查看。任务明确命名为“拉伸曲线分析（已有数据）”。
5. 再录入两个 200°C 独立试样，虚构数值 315/9、325/10。第一条复核后提示 n=1、重复数不足；第二条复核后得到 n=2、320.00 ± 7.07 MPa、9.50 ± 0.71%。这些是软件验证值，不能用于科研。
6. 指定 2 个复测样、1 个明确工艺变量的对照样、0 元测试成本与停止条件。确认后进入第 2 轮，新增 `R2-9fa55a-1/2/3`，项目共 4 个样品；第 1 轮记录仍在历史归档中。
7. 第 2 轮人工通道实际走过任务定义、路线确认、登记开始、回传虚构 TXT、等待验收、验收完成。没有实际材料制备或设备动作。样品实物进度需要按实际执行记录核对，不能仅凭软件状态认为已经制备。
8. 账号默认设置和项目覆盖项均能显示正确作用对象；没有为测试改变该账号的隐私授权或模型默认值。
9. 使用项目检索式 `Al-Cu-Mg 200 C alloy tensile properties`、期刊论文、2020–2026 年，实时 Crossref 返回 5 条，全部为期刊题录，仍需核对材料相关性和正文许可。
10. 账号对话能同时引用目标、最近历史结果和当前轮次，明确第 2 轮尚无结果；服务重启后会话、项目、文件和轮次仍可读取。
11. 390 × 844 视口下结果页无整体横向溢出（文档宽度与滚动宽度均为 390）；检查后恢复正常视口。
12. 新对话提出研究需求，点击草稿入口后原文完整带入；数值提取为 300 / 8 / 200 / 6 / 4，未给定的标准、环境、重复数等仍待确认。关闭草稿没有创建项目。从长指南底部跳转成员页后，页面稳定时滚动位置为 0。

## 你可以如何验收

开发入口：[测试指南](http://127.0.0.1:4317/platform-guide)，也可直接打开 [研发工作区](http://127.0.0.1:4317/workspace)。从侧栏选择 FIX-906 查看已有测试状态，或新建独立研究测试。

建议依次检查目标提取与缺失拦截 → 115% 成分拒绝 → 不同温度结果 → 独立试样统计 → CSV 计算/人工回传 → 下一轮生成。曲线样例可从测试指南下载，也位于 `server/fixtures/platform/FICTIONAL_SOFTWARE_TEST_curve.csv`。人工回传样例为同目录的 `FICTIONAL_MANUAL_RECEIPT.txt`。所有样例均为虚构。

启动：`npm run dev:platform:start`；状态：`npm run dev:platform:status`；停止：`npm run dev:platform:stop`。服务重启保留 `.dev/knowledge-data`。**是否部署仍由用户验收决定。**

## 尚未完成真实连接的能力

当前已打通软件数据和人工回传闭环，不能据此宣称具备完整自主材料实验室能力。后续需要明确可访问的仿真引擎/集群与数据库许可、设备接口、真实模型服务、组织成员加入和生产计费渠道，再用真实材料数据验收。CSV 分析是数据处理，不是 DFT 或材料性能预测。
