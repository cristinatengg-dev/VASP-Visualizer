# EliangMat AI 账号自动记忆验收

当前为本机开发版，未部署生产。正常使用对话、项目、资料和设备页面即可；不需要单独创建记忆条目。

## 入口与操作

- 对话：http://127.0.0.1:4317/assistant 。首页进入工作区也会到这里。
- 项目协作：http://127.0.0.1:4317/workspace ，沿用相同的账号级检索。
- 设置：http://127.0.0.1:4317/account/memory ，默认只显示自动记忆开关；来源管理折叠收起。
- 旧 `/workspace/memory` 地址转到账号设置，项目导航与每条消息的「保存记忆」按钮已移除。

运行 `npm run dev:platform:start` 启动。手机号登录后使用；当前验证码为页面明确标注的本机测试码，不发送短信。重启保留有效会话，同一手机号重新登录恢复原资料、对话和版本。客户 A/B 从登录页或左下角账号菜单的「开发测试」进入。详见 [登录验收指南](PHONE_LOGIN_DEV_GUIDE.md)。

## 默认行为

1. 在对话里补充信息会自动持久保存。点击「新对话」后，界面是空白对话，但检索仍可找到此前内容；历史对话可以切回。
2. 同一客户账号内自动检索有权访问的项目，无需逐个项目授权引用。回答保留项目名与来源；其他项目的工艺、配方、目标和预算不会自动覆盖当前项目。
3. 自动参考已有用户讨论、项目目标、路线、任务、候选、样品、实验记录、复核和决策，以及资料目录、获准检索的正文、复核证据、设备接入说明和模型选择。
4. 账号的余额、订单、用量、预算与成员信息只有所有者可以检索。所有者的账号对话按角色隔离，研究员不能通过历史会话或引用详情读取；项目协作仍按现有研发角色权限共享。
5. 所有客户始终隔离。私密只表示数据不参与公司训练，不妨碍客户在自己的账号中使用记忆；记忆开关、模型选择和训练同意相互独立。
6. 修改项目数据或资料后，下一次检索读取当前版本。旧引用会重新检查版本和权限，失效后不展示旧内容；不复制证据正文到回复中绕过许可。
7. 管理区可以停止引用某条记录，或排除某个项目。主开关关闭后，全账号与项目协作都停止读取记忆，但原始历史仍保留。既有的停用设置不会被升级重置。

## 推荐验收

1. 以客户 A 进入「对话」，输入 `【验收示例】报告代号 AC-882 采用结论在前、证据在后的格式。这不是客户真实偏好。`，发送即可，无需点击其他保存按钮。
2. 点击「新对话」，询问 `AC-882 的报告格式是什么？`。应直接显示之前的记录和来源，可展开查看；历史会话不需要复制到新会话中。
3. 在项目协作页提出相同问题，应能自动找到账号对话中的记录。反过来，在「对话」中问某个项目已约定的条件或进展，应能找到该项目记录，且来源标明项目名。
4. 修改演练项目目标或设备接入说明，直接回到对话提问，检查读取的是当前值。资料只有元数据时只能定位目录，不能假装读过正文；正文须已获检索许可，未复核内容有明确标识。
5. 打开自动记忆设置 → 展开管理区 → 选择来源范围 → 停止引用测试记录。回到对话重新问，应不再引用；原引用打开详情也会校验权限。验收后停止引用测试偏好，避免以后当成真实信息。
6. 在设置中关闭主开关，再提问，页面应明确说明未读取历史。重新开启后恢复读取；关闭与恢复不改变数据训练授权。
7. 刷新或重启开发服务后再次进入，确认对话列表、当前会话和可检索背景仍在。切客户 B，不应看到 A 的任何对话或资料；研究员不能读取所有者账务和账号会话。
8. 可在管理区查看已有人工条目的修订历史、更正或删除；自动来源可停止引用，完整导出包括历史记录。原始项目表单仍是研究目标、预算和实验数据的修改入口。

## 当前边界

- 已实现持久保存、自动覆盖已有记录、账号级本地检索和动态来源校验；尚未接入真实大模型推理、语义向量搜索、任意自然语言事实提取和冲突合并。当前回复展示检索到的原始记录，不应把它描述为已经具备完整大模型推理能力。
- 自动保存讨论不等于认可其中的科学结论。研究假设、原始讨论、未复核正文和演练数据保留相应状态。自然语言更正可以补充背景；需要改变执行目标或实验数值时，仍需更新相应表单。
- 系统只记得已录入本账号且有权读取的信息。无法恢复功能启用前已被覆盖的历史。历史版本从启用时现状建立基线。
- 单进程原子 JSON 开发存储，每客户状态上限 50 MB（不含独立原件）；超限拒绝新写入而不丢弃旧历史。对话无旧的 200 条裁剪；人工条目每范围最多 500 条。
- 正式多人部署前仍需真实用户/组织权限、数据库、并发与备份恢复；开发角色切换接口不能上线。未接通模型、付款、设备控制或训练。

## 验证与实现

自动测试：`npm run test:platform`。记忆专项：`npm run test:memory`。静态检查：`npm run typecheck`。构建：`npm run build`。

前端：`src/pages/platform/Assistant.tsx`、`Memory.tsx`、`Research.tsx`。后端：`server/src/memory/`、`server/src/platform/`。状态保存在 `.dev/knowledge-data/<客户散列>/state.json`。

保留旧的逐条跨项目授权 API 仅供显式关闭账号自动跨项目读取的兼容场景，不再作为默认交互。

本轮验证：20 项记忆专项测试、41 项合并测试通过；TypeScript、相关前端 ESLint 与构建通过。浏览器验证直接补充、新会话回忆、重启恢复、来源详情、停止引用、账号对话读取其他项目和 390px 布局。ELM-902 验收偏好已停止引用，原始对话保留。
