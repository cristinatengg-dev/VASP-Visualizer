# 对话过程开发验收

2026-09-06。仅本机开发环境，未提交、推送或部署。

## 当前体验

- [账号对话](http://127.0.0.1:4317/assistant)和[项目协作](http://127.0.0.1:4317/workspace)均已接入。发送后立即显示问题、真实处理阶段和持续更新的耗时；Gemini 返回的正文逐段显示。
- 过程记录包括收到问题、读取获准参考的记录、等待 Gemini 回复、连接成功、接收正文、完成。只有实际事件发生才显示该步骤，没有模拟材料分析步骤或假打字延时。
- 完成后收起为「处理完成 · 耗时」，点击可展开。停止或失败明确显示未完成状态，已收到的部分正文保留为未完成回复；刷新仍能查看已保存的完成/失败/取消记录。
- 发送按钮在生成期间变为停止按钮。停止会取消浏览器接收并中断后端上游连接；供应商已处理的 Token 仍可能计费，未返回用量不显示为零。
- 只接受供应商明确提供的公开 `reasoning_summary` 字段，并标注「模型提供的摘要」。不展示原始推理、分析通道或签名。当前网关实测没有返回独立摘要，页面展示真实处理记录。已有历史回答不补造过程。
- 原账号/项目授权、来源有效性检查、私密模式和用量记录继续生效。来源或网关授权中途失效时停止输出；历史回答随来源失效隐藏。没有自动执行材料实验、仿真或修改研究目标。

## 手工验收

1. 启动 `npm run dev:platform:start`，进入账号对话，选择已授权的 Gemini 3 Flash，创建新对话。可输入「【软件验收，数据虚构】根据当前项目，用两句话列出下一步待核对的条件，不执行任务」。
2. 发送后应立即出现问题和展开的过程记录，耗时随等待更新。首段正文收到后进入「正在接收回复」。供应商有时首段需要数十秒，期间应一直保留状态和停止入口。
3. 完成后检查正文、模型、实际 Token 与来源；过程行自动收起，点击可展开。刷新后再展开，检查步骤与耗时保留。
4. 新建另一条对话，发送问题后点击「停止生成」。应显示「已停止」，不显示完成，不把未知用量显示为零；刷新后保持取消状态。取消后可继续新问题。
5. 在项目模型页单独选择并授权 Gemini，进入项目协作发送一条标明虚构的软件测试问题，重复上述流程。
6. 在 390px 窄屏展开过程，检查没有整体横向滚动，模型选择、输入框和发送/停止按钮可用。

## 实现边界

开发数据仍使用独立本机存储。完成、取消或失败时保存正文和过程；硬重启中断的调用保留中断状态，但不会逐 Token 写盘保证恢复尚未保存的片段。真实费用结算仍按 Gemini 接入说明处理，未启用生产钱包扣费。

外部供应商如果忽略流式参数而返回普通 JSON，会在收到完整响应时一次显示正文，不伪造逐字生成。中途断流明确报错，不自动重试以免重复计费。
