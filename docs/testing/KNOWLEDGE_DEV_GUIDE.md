# EliangMat AI 数据中心开发验收

该模块现已整合到全平台导航；首页为 **http://127.0.0.1:4317/**，完整步骤见 [全平台指南](PLATFORM_DEV_GUIDE.md)。资料入口为 **http://127.0.0.1:4317/knowledge**。生产环境没有部署，也没有启用新接口。用户明确反馈测试通过后，再安排部署。

## 打开、启动与停止

- 当前已在本机后台运行。打开上面的地址，登录页展开「开发测试」→「进入客户 A 演练」，即可继续原资料；也可使用手机号建立独立账号，默认显示本机测试验证码且不发短信。详见 [登录指南](PHONE_LOGIN_DEV_GUIDE.md)。
- 电脑重启后，双击仓库根目录的 `启动EliangMat开发环境.command`，会启动后台服务并打开浏览器。
- 也可以在项目目录执行：

```bash
npm run dev:knowledge:start
npm run dev:knowledge:status
npm run dev:knowledge:stop
```

需要边修改边看日志时，先停止后台服务，再运行 `npm run dev:knowledge`；按 Ctrl+C 停止。前端支持热更新，后端代码和配置改动后需要重启。

地址仅供这台电脑访问。关闭浏览器或终端不会停止后台服务；电脑休眠、关机或手动停止服务时不可访问。它不是外网测试站点。

如需在另一台开发机安装，使用 Node.js 22.16+ 或 24（本机验证版本为 24.13.0），先执行 `npm ci` 和 `npm --prefix server ci`，再执行启动命令。不需要 Docker、MongoDB、短信或生产模型密钥。

## 建议按顺序验收

| 步骤 | 你要操作什么 | 应看到什么 |
| --- | --- | --- |
| 1. 项目 | 选择客户 A，新建任意项目 | 项目默认私密；各项目资料和任务分开 |
| 2. 真采集 | 资料库 → 采集文献 → Crossref；输入 `nickel based superalloy`，采集 10 条 | 任务从排队/采集中变成完成；能看到真实题录、DOI 和来源 |
| 3. 去重 | 采集任务 → 重新采集本批 | 相同记录计为重复，资料总量不膨胀；上游改变的记录保留新版本 |
| 4. 分页 | 已完成批次 → 继续下一批 | 创建新的批次，使用服务端保存的游标继续；不宣称已抓取全部匹配结果 |
| 5. 专利导入 | 测试指南下载 JSONL 样例 → 资料库导入 | 2 条资料校验入库；再次导入显示重复；错误行号有清楚提示 |
| 6. 材料证据 | 打开样例专利详情 | 实施例与权利要求分开；显示成分、wt% / at%、工艺、条件、原文和页码 |
| 7. 复核 | 点确认复核，关闭详情再打开 | 复核状态保留；资料库的已复核数量更新；操作记录可见 |
| 8. 正文 | 在真实文献详情 → 正文与摘要，上传自己有权处理的 PDF 或 UTF-8 TXT | 提取正文与实际页码；不带文本层的扫描件会提示需要 OCR |
| 9. 引用校验 | 从正文复制一段文字，添加材料证据；再试一段不存在的文字 | 匹配原文的引用可保存；虚构或错页的引用被拒绝 |
| 10. 用途许可 | 资料详情 → 使用许可，填写具体依据并勾选用途 | 客户声明被记录；仅开放全文链接或项目授权不会自动开启正文用途 |
| 11. 私密 | 权限与用途保持私密 | 训练候选按钮禁用，绕过按钮调用 API 也会返回 403 |
| 12. 参与优化 | 切换参与模型优化，完成明确确认 | 仍需内容训练权、全部证据复核，且不能是演示数据；任一条件缺少都会被挡住 |
| 13. 撤回 | 切回私密 | 后续训练候选导出立即关闭。已下载副本不会自动删除；本版没有实际训练任务 |
| 14. 账号隔离 | 切换客户 B，再切回 A | B 看不到 A 的项目、原件或证据；切回 A 数据仍在 |
| 15. 重启 | 停止服务、重新启动、选择同一账号 | 项目/资料/许可/任务仍在；中断的采集会标为可重试 |

对真实内容的训练权声明应依据实际许可证或合同。为了演示而编造的样例不可改作真实训练数据。

## 配置与故障定位

启动时会创建 `.dev/knowledge.env`，只读取以下三个配置。密钥只留在服务端，不回传页面。

```dotenv
OPENALEX_API_KEY=
CROSSREF_EMAIL=
UNPAYWALL_EMAIL=
```

- Crossref 可直接使用，填写真实联系邮箱可进入 polite pool。
- OpenAlex 已实现匿名/Key 两种接入。若出现限流，可在官方账户获取 Key 填入并重启；不能保证 Key 自动解除账户额度限制。
- Unpaywall 需要真实联系邮箱。在带 DOI 的文献详情点击查找，只定位 OA 副本，不自动下载。
- `4317` 是前端，`4318` 是开发 API。端口被占用会直接报错，不会悄悄换地址。
- 日志：`.dev/knowledge.log`；状态：`npm run dev:knowledge:status`。
- 开发数据：`.dev/knowledge-data`；账号身份：`.dev/platform-auth`。停止服务后一起备份这两个目录，保留账号映射、状态与原件；不要只复制 `state.json` 而漏掉原件和账号索引密钥。备份应保持仅本人可读，不上传到 Git。
- `.dev` 已被 Git 忽略。开发服务不读取 `server/.env`，也不初始化生产账户、MongoDB、支付、付费模型或计算作业。默认不发送短信；可使用独立 `.dev/phone-auth.env` 显式启用腾讯云短信。

## 本版范围与后续工作

**已实现**：Crossref/OpenAlex 小批量题录采集；标准 JSONL 文献/专利导入；PDF/TXT 正文解析；原始批次与 SHA-256 溯源；DOI/公开号去重；失败、重试、继续分页与重启恢复；材料证据摘录/导入及人工复核；逐项目私密/参与优化；按用途校验的题录、全文缺口、RAG 证据和训练候选导出。

**尚未实现或尚未开通**：CNIPA/EPO/USPTO/WIPO 原始格式与机构数据连接；全球全量快照；无人值守增量调度；OCR、自动表格/材料字段抽取；自动向研发智能体注入检索上下文；实际模型训练/评估；组织成员与项目角色；生产模型选型和充值账单。目前全平台已实现成员草稿、开发角色测试、项目模型选择及虚拟充值/用量账单；生产组织身份和真实付费服务尚待接通。

存储目前是单进程试用存储：每账号最多 30 项目、3,000 份资料、500 批任务；每批 JSONL 最多 500 条/5 MB；单份正文最多 5 MB、200 页、100 万字符。它适合验收此工作流，不适合全球语料吞吐或多个服务实例共同写入。大规模版本需要数据库索引、对象存储与持久任务队列后再做容量测试。

生产端已挂好**默认关闭**的 `ENABLE_KNOWLEDGE_PILOT=1` 接口开关，访问必须使用已验证登录令牌；没有测试账号后门。生产部署前需针对拟上线规模确定存储方式、持久卷和备份，并完成账户及内容许可核验。
