# 腾讯混元迁移：本地验收与上线条件

2026-09-28。代码已在本机完成迁移；**尚未开通云服务、配置真实混元密钥、调用真实模型或部署生产**。不能将本记录当作线上已切换或备案已通过的证明。

## 实际迁移范围

- 正式平台入口 `server/platform.cjs`、预览及知识开发入口只创建腾讯混元网关，不再读取 Gemini 配置或自动回退到旧模型。遗留独立应用不在本次迁移范围，不能据此声称仓库所有旧功能已改接混元。
- 仅允许国内官方 `https://tokenhub.tencentmaas.com/v1`，禁止重定向与任意代理地址。默认型号 `hy3`；显式支持 `hy3-preview`、`hy4-preview`，实际可用性须在腾讯云账号中确认。
- 使用专用 `HUNYUAN_API_KEY`，不是短信 CAM SecretId/SecretKey，也不复用旧 Gemini 密钥。密钥为空时仅开放本地检索，不显示已接通外部推理。
- 普通及 SSE 回复必须携带可核验的混元型号，保存实际型号、请求标识及返回的 Token 用量。未返回的用量不补零，错误或半途断流不算成功；原始思维链不进入前端。
- 账号对话、项目对话及账号默认项分别确认外发范围。供应商、官方接口或型号变化会使旧授权失效；旧弹窗的确认也不能授权新配置。调用前与流式过程中继续验证资料权限。
- 已有 Gemini 对话、历史用量和原授权按原始来源保留，不改名成混元。旧模型选择在读取时回到本地检索，不批量改写历史存储。
- 隐私政策和服务条款按“选用腾讯混元时”的实际处理方式说明，没有声称本平台已获得 AI 相关资质。

## 上线前必须完成

1. 经账号所有者确认，为 TokenHub 授予控制台要求的服务关联角色，并同意开通条款及按量计费规则。本轮控制台停在授权/开通阶段，尚未确认执行。
2. 使用专用、最小模型范围的 TokenHub API Key，确认 `hy3` 在该账号可调用。通过安全配置渠道写入服务器受保护的 `.config/platform.env`，不要放入聊天、Git、前端环境变量或截图。
3. 四个模型配置项见 `scripts/platform/platform.env.example`：`HUNYUAN_BASE_URL`、`HUNYUAN_API_KEY`、`HUNYUAN_TEXT_MODEL`、`HUNYUAN_MAX_OUTPUT_TOKENS`。预览只读取 `.dev` 白名单文件，不继承生产配置。
4. 明确获准的真实测试及费用范围，以虚构、无敏感内容验证一次普通回复与流式回复，核对供应商返回的实际型号和用量。当前自动化使用 mock，不能替代此项。
5. 按现行独立 platform 架构通过 GitHub 同步发布，先做一致性数据快照并保留原镜像与配置。不得使用旧后端的首次部署脚本。`eliangai.com` 和 `scivisualizer.com` 共用该实例，切换会影响两个站点。
6. 验证两域健康与登录入口、重新确认混元的数据范围、发送虚构测试问题、核对新用量，同时确认旧对话仍显示原始来源；失败时停止外部推理，不暗中回退 Gemini。

模型迁移不等于备案材料齐全或审核通过。应以实际上线功能、实际接入型号及腾讯提供的有效材料向审核方说明，其他登记及实名要求仍需单独核实。
