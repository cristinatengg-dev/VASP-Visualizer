# Gemini 接入开发验收

2026-09-06。仅本机开发环境，未提交、推送或部署。

## 当前接入

- 复用之前 `api.aipaibox.com/v1` 网关与服务端 Gemini 密钥，使用 OpenAI 兼容的 `chat/completions` 协议。不是把外部模型改名成 EliangMat 自有模型。
- 原配置 `gemini-2.5-flash` 实测 HTTP 503，网关 `/models` 不再列出该型号；改用网关列出的 `gemini-3-flash`。真实接口已返回该模型名、文本与 Token 用量。
- 专用后端配置为 `.dev/model.env`，只读取 `GEMINI_BASE_URL`、`GEMINI_API_KEY`、`GEMINI_TEXT_MODEL`。本次从既有服务端配置中只复用了这三项；开发启动不会加载整个 `server/.env`，不连生产数据库、支付或短信。密钥不进入浏览器或 Git；文件权限 600。
- 示例文件：`scripts/knowledge/model.env.example`。修改后运行 `npm run dev:platform:stop`、`npm run dev:platform:start`。不要把密钥填在项目说明、对话或前端环境变量里。

## 页面怎么测试

1. [账号对话](http://127.0.0.1:4317/assistant)：输入框旁选择 Gemini 3 Flash，确认显示的网关和数据范围后发送问题。回复附真实输入/输出 Token；新对话仍可检索获准保留的相关约定。
2. [项目模型](http://127.0.0.1:4317/workspace/settings/models)：选择 Gemini 后，当前项目协作区使用它。账号对话模型与项目模型分别保存，账号默认项仍只影响新项目。
3. 项目数据仍保持原来的私密/参与优化设置。外部推理与公司训练授权独立；旧版未明确网关的通用确认不能直接授权 Gemini。
4. 外发上下文是本地权限检索结果，再按当前网关授权过滤。其他项目未经单独确认不进入 Gemini 上下文。始终不外发其他账号记录，且研发推理过滤账务/成员管理记忆。
5. 在项目模型页点击「停止外部推理」，项目对话回到本地检索，账号 Gemini 也不再自动读取该项目。切换账号对话回本地检索停止该范围的新调用。
6. [余额与用量](http://127.0.0.1:4317/account/billing) 增加「真实模型调用」：状态、网关、实际模型、Token、时间与失败原因。原 TEST 充值和计费演练保留。

## 费用与限制

Gemini 调用会产生供应商 API 用量，由已有 API 账号承担。网关没有向当前平台配置经过核实的价格，因此本版只记录接口返回的 Token，不估算实际费用、不扣 TEST 钱包，也不把现有示例价格用于 Gemini。缺失 Token 字段显示「—/未返回」，不是零。生产按充值余额扣费还需配置网关费率和结算渠道。

每次最多 2048 输出 Token、60 秒超时；同一账号最多一个进行中的模型调用，每分钟最多 6 次。账号和项目对话已接入真实 SSE 流式输出，显示处理阶段、耗时和停止按钮；完成后可以展开过程记录，详见[对话过程开发验收](CHAT_PROCESS_DEV_GUIDE.md)。超时、空回复、鉴权/限流失败会明确报错；部分回复标记未完成，保留请求记录，不伪造成功文本。停止、超时或重启时供应商可能已处理，需要与供应商账单核对；不自动重试。相同请求标识幂等，重启中断保留状态。

Gemini 只分析与给出可确认建议，不自动改目标、创建项目、授权、扣费、训练或执行设备/仿真。真实引擎和硬件仍需独立接入。模型回答不作为自动通过材料研究验收的依据。

## 验证

自动化测试覆盖真实响应结构、缺失用量、错误脱敏、HTTP 等待异步回复、网关授权、角色/客户隔离、来源撤销、历史连续性、关闭记忆、重复请求、失败与重启中断、停止外发。

本轮 Computer Use 使用原虚构测试账号与 `FIX-906 材料闭环回归 · 全部虚构`，不上传真实科研数据。项目问题实测返回第 2 轮、200°C、300 MPa，并说明第 1 轮历史数据不能证明第 2 轮达标。接口记录输入 918、输出 1205 Token；测试余额仍为 99.95 元。账号切换确认中的嵌套表单问题已在实测中发现并修正。账号对话真实记录虚构约定后，新对话成功找回「先温度、后标准」，显示来源；两次输入/输出分别为 1188/925、360/444 Token。用量页三条真实调用均完成，TEST 余额未变。390px 窄屏对话无横向溢出，模型选择和输入框可见。

接入流式过程后，`npm run test:platform` 共 80 项通过；TypeScript、相关前端 ESLint 与构建通过（保留既有 3D 文件体积提示）。

最后重启开发服务并重新加载页面，账号 Gemini 选择、最新回复、来源和 Token 仍保留。浏览器已恢复正常尺寸，停留在可继续使用的账号对话页。
